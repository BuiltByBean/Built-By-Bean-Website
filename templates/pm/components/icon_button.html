{# An action whose glyph carries the meaning, as one control. Catalogue rule "Sign out is an icon, never a label". Edit and delete are the two most common actions in an admin and the two most universal glyphs after close, and they kept shipping as the words "Edit" and "Delete" because a bordered text button looks deliberate rather than unstyled. This exists so the fix lives in one place: the rule that gets forgotten at a call site is never the geometry, it is the accessible name, so the macro refuses to render without one. Not for a form's submit. The button that commits fields says what it does in words ("Add a note", "Save Aug 2026"); this is for the action slot on a row or a header, where the buttons sit side by side and position already says what they are. name a key from GLYPHS below label what a screen reader and a hover say. Required. href renders an anchor; omit for a button tone 'quiet' (default), 'brand' for the primary, 'danger' for destructive type submit or button, when it is a button target for an anchor that leaves the app attrs anything else, dropped on the element verbatim 44px square, the house control size, and the same rounded-xl every other control in a bar uses (catalogue rule "One shape for every control in a bar"). The svg is aria-hidden so the name is read once, not twice. #} {#- Each name is a concept of the icon vocabulary (Handbook, Icons), except 'map', which is the business map. -#} {% set GLYPHS = {'map': 'business-map'} %} {% set TONES = { 'quiet': 'border border-white/10 text-surface-400 hover:border-brand-500/40 hover:text-brand-300', 'brand': 'btn-brand text-white', 'danger': 'border border-white/10 text-surface-400 hover:border-red-500/40 hover:text-red-300' } %} {% macro icon_glyph(name, size='w-5 h-5') %} {{- icon(GLYPHS.get(name, name), size) -}} {%- endmacro %} {% macro icon_button(name, label, href='', tone='quiet', type='button', target='', attrs='') %} {#- An unnamed control is a worse bug than the caption was, so it is not optional: with no label the button is not drawn at all, which shows up the moment the page is opened rather than silently on a screen reader. -#} {%- if not label -%} {%- else -%} {%- set shape = 'inline-flex items-center justify-center w-11 h-11 rounded-xl transition-colors shrink-0' -%} {%- if href -%} {{ icon_glyph(name) }} {%- else -%} {%- endif -%} {%- endif -%} {% endmacro %} {# The destructive one, which is the same glyph plus the in-place question (LM-2: never confirm()).
